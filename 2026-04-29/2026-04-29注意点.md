# 2026-04-29 注意点

1. `Path.exists()` 必须加括号

   错误写法：

   ```python
   if not path.exists:
       return {}
   ```

   正确写法：

   ```python
   if not path.exists():
       return {}
   ```

   原因：`exists` 是方法，必须用 `()` 调用。否则判断的是方法对象本身，不是在判断文件是否存在。

2. `path.suffix` 返回的后缀自带点号

   错误写法：

   ```python
   if path.suffix in ["yaml", "yml"]:
       ...

   elif path.suffix == "json":
       ...
   ```

   正确写法：

   ```python
   if path.suffix in [".yaml", ".yml"]:
       ...

   elif path.suffix == ".json":
       ...
   ```

   原因：`Path("config.yaml").suffix` 的结果是 `".yaml"`，不是 `"yaml"`。

3. `yaml.safe_load` 不要拼错

   错误写法：

   ```python
   yaml.safae_load(f)
   ```

   正确写法：

   ```python
   yaml.safe_load(f)
   ```

   记忆：`safe_load` 表示安全加载 YAML。

4. `try/except` 里捕获错误后要记得 `return {}`

   推荐写法：

   ```python
   try:
       return yaml.safe_load(f) or {}
   except yaml.YAMLError as e:
       print(f"[错误] YAML 解析失败: {e}")
       return {}
   ```

   原因：解析失败时要给调用者一个明确结果，避免函数返回 `None`。

5. 不支持的文件格式也要返回空字典

   推荐写法：

   ```python
   else:
       print(f"[警告] 不支持的文件格式: {path.suffix}")
       return {}
   ```

   原因：`load_config()` 的设计目标是始终返回字典。失败时返回 `{}`，后面可以用 `if not config:` 判断。

7. `PyYAML` 没安装会导致 `import yaml` 报错

   报错示例：

   ```text
   ModuleNotFoundError: No module named 'yaml'
   ```

   安装命令：

   ```bash
   pip install pyyaml
   ```

   如果使用 conda 环境，先激活环境：

   ```bash
   conda activate llm-engineer-roadmap
   pip install pyyaml
   ```

8. 激活环境后，不要再写死另一个 Python 解释器路径

   容易出错的运行方式：

   ```bash
   f:\Python_AI_Project\pythonProject\.venv\Scripts\python.exe f:/Python_AI_Project/llm-engineer-roadmap/2026-04-29/config_loader.py
   ```

   推荐方式：

   ```bash
   conda activate llm-engineer-roadmap
   python f:/Python_AI_Project/llm-engineer-roadmap/2026-04-29/config_loader.py
   ```

   原因：写死解释器路径会绕过当前激活的 conda 环境。


10. `class` 是类，是创建对象的模板

    示例：

    ```python
    class ExperimentManager:
        ...
    ```

    可以理解为：`ExperimentManager` 是一个实验管理器模板。

    创建对象：

    ```python
    mgr = ExperimentManager()
    ```

    `mgr` 才是真正可以使用的实验管理器对象。

11. `__init__` 是对象创建时自动执行的方法

    示例：

    ```python
    def __init__(self, base_dir="experiments"):
        ...
    ```

    当执行：

    ```python
    mgr = ExperimentManager()
    ```

    Python 会自动执行 `__init__`，用来初始化对象。

12. `base_dir="experiments"` 是默认参数

    默认写法：

    ```python
    mgr = ExperimentManager()
    ```

    等价于使用：

    ```python
    base_dir = "experiments"
    ```

    也可以自定义：

    ```python
    mgr = ExperimentManager("my_experiments")
    ```

13. `self` 表示当前对象自己

    示例：

    ```python
    self.base_dir = Path(base_dir)
    ```

    如果对象是：

    ```python
    mgr = ExperimentManager()
    ```

    那么可以粗略理解为：

    ```python
    mgr.base_dir = Path("experiments")
    ```

14. `base_dir` 和 `self.base_dir` 不是同一个东西

    示例：

    ```python
    def __init__(self, base_dir="experiments"):
        self.base_dir = Path(base_dir)
    ```

    `base_dir` 是传进来的参数，默认是字符串 `"experiments"`。

    `self.base_dir` 是保存在对象身上的属性。

    `Path(base_dir)` 是把字符串路径转换成更好用的 `Path` 对象。

15. `Path(base_dir)` 的作用是把字符串路径升级成路径对象

    字符串路径：

    ```python
    "experiments"
    ```

    Path 对象：

    ```python
    Path("experiments")
    ```

    Path 对象可以直接调用：

    ```python
    self.base_dir.mkdir(parents=True, exist_ok=True)
    self.base_dir.exists()
    self.base_dir / "my_first_exp"
    self.base_dir.iterdir()
    ```

16. `class ExperimentManager()` 可以写，但更推荐不加括号

    可以运行：

    ```python
    class ExperimentManager():
        ...
    ```

    更推荐：

    ```python
    class ExperimentManager:
        ...
    ```

    原因：没有继承别的类时，括号不是必须的。
